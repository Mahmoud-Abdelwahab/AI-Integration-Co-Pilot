# Moyasar iOS SDK Documentation

Accept payments in your iOS app with Moyasar's secure payment SDK.

---

## Quick Start

### 1. Install the SDK

Choose your preferred installation method:

- **Swift Package Manager (SPM)**: [Installation Guide](/sdk/ios/installation#swift-package-manager)
- **CocoaPods**: [Installation Guide](/sdk/ios/installation#cocoapods)

### 2. Choose Your Payment Method

| Payment Method | Description | SwiftUI Support | UIKit Support |
|----------------|-------------|-----------------|---------------|
| [Credit Card](/sdk/ios/credit-card-integration) | Accept Visa, Mastercard, Mada, and AMEX payments | ✅ Built-in `CreditCardView` | ✅ Built-in `CreditCardView` |
| [Apple Pay](/sdk/ios/apple-pay-integration) | Seamless checkout with Face ID/Touch ID | ✅ `PKPaymentButton` wrapper | ✅ `PKPaymentButton` |
| [STC Pay](/sdk/ios/stc-pay-integration) | Accept STC Pay mobile payments | ✅ Built-in `STCPayView` | ✅ Built-in `STCPayView` |
